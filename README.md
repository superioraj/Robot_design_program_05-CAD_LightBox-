# ROBOT SKETCH CAD 3.0

단색 녹색 CRT 로봇 스케치 앱입니다.

## 이번 수정
화면에 나타난 가로선 1개와 대각선 2개는 기본 도안이 아니라 이전 실행에서 브라우저 `localStorage`에 저장된 사용자 선이었습니다. 이번 버전은 저장 공간 키를 `robotSketchMono.v6`으로 변경하여 처음 실행할 때 저장된 세 선을 불러오지 않습니다.

새 버전의 초기 화면에는 다음 두 개의 기본 부품만 나타납니다.
- RING:BIT / AAA PACK
- MG90S 서보모터

이후 학생이 새로 그린 선은 F3 임시 저장과 자동 저장으로 v6 공간에 정상 보존됩니다. F2 모두 지우기를 누르면 다시 기본 부품 두 개만 배치됩니다.

## PDF 출력
흰색 배경, 검정색 선으로 출력하며 학생이 선택한 2px, 4px, 8px, 12px 선 굵기와 부품 SVG의 원래 선 굵기를 유지합니다.

## GitHub Pages
`index.html`과 `README.md`를 저장소 루트에 올리고 Settings > Pages에서 main 브랜치 root를 선택합니다.
